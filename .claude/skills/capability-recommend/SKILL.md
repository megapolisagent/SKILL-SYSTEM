# capability-recommend — точка входа для нативной авто-загрузки Claude Code

Это не отдельная копия протокола — это точка входа, чтобы Claude Code (project-scope `.claude/skills/`) реально подхватил Skill. Источник истины и полный протокол — `skills/capability-recommend/SKILL.md` в корне этого репозитория (тот же файл, что зарегистрирован в `registry.json`/`CATALOG.md` через обычный lifecycle).

**Прочитай и выполни `skills/capability-recommend/SKILL.md` целиком, начиная с этого момента.** Не пересказывай его, не сокращай — следуй протоколу Find → Match → Gap → Discover → Assemble из него дословно.
