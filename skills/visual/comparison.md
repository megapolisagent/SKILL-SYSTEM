# Сравнение с мировыми альтернативами

Дата: 2026-08-10. Проведено при первом реальном прогоне Skill'а `visual` через Skill System — задача была не просто оценить сам файл, а понять, лучший ли это способ решать задачу генерации медиа, прежде чем считать его принятым в библиотеку. Источники — первоисточники (SKILL.md открыты напрямую), не пересказ.

## Что есть у VelsVisual

CLI на Node.js (ноль зависимостей), единственный провайдер — KIE (kie.ai), живой (не зашитый) реестр моделей, обязательная проверка стоимости с конкретными числовыми порогами ($1 / 10% баланса) перед тратой денег, раздел реальных «граблей» из практики.

## Найденные альтернативы

| Skill | Источник | Провайдер(ы) |
|---|---|---|
| genmedia | `fal-ai-community/skills` (github) | fal.ai, 1200+ моделей |
| crun-agent-skills | `CrunTeam/crun-agent-skills` (github) | Crun, 138 моделей / 15+ провайдеров |
| media-generation | `onimusya/media-gen` (github) | 11 провайдеров (OpenAI, Google, Fal, Replicate, ElevenLabs и др.) |
| muapi-media-generation | `SamurAIGPT/Generative-Media-Skills` (github) | muapi.ai, 100+ моделей |

## Кто сильнее по отдельным задачам

- **Найти модель без точного названия** — genmedia: `genmedia run "кот на луне"` сам классифицирует запрос. У VelsVisual всегда два шага (`models --search`, потом `run`).
- **Безопасность/согласие на работу с чужим лицом или голосом** — crun-agent-skills: прямой текст про отказ на имперсонацию, фрод, non-consensual контент, обязательное подтверждение прав. У VelsVisual такого раздела нет вообще.
- **Не зависеть от одного платного шлюза** — onimusya/media-gen: 11 провайдеров, часть операций (Edge TTS) бесплатна без ключа.
- **Показать результат сразу** — muapi: флаг `--view` для прямого показа медиа в терминале.
- **Готовые сценарии «под ключ»** (не сырой вызов модели, а конечный результат) — muapi (41 рецепт); никто из остальных, включая VelsVisual, этого не делает.

## Где VelsVisual уникален

Единственный из четырёх, у кого в SKILL.md есть раздел с конкретными наблюдёнными сбоями и их обходами (ошибка копирайта на аудио-дорожке видео, обрезка кадра дефолтным aspect_ratio, путаница именования поля картинки) — практическое знание, добытое реальным использованием, не из документации. Также единственный, кто даёт человеку понятные денежные пороги ($1 / 10% баланса), а не просто программную проверку affordable/не affordable.

Оговорка: проверялись только главные SKILL.md альтернатив, не все их `references/`-файлы — возможно, у кого-то троллшутинг-знание спрятано глубже.

## Где он слабее

Нет раздела про согласие/безопасность при работе с чужим лицом/голосом; один провайдер вместо нескольких; нет умной маршрутизации, всегда ручной поиск; нет бесплатного пути ни для одной операции.

## Что можно взять из других решений

- Раздел про согласие/безопасность для лица и голоса — у crun-agent-skills, можно взять как текстовый образец.
- Идея умной маршрутизации по умолчанию — у genmedia.
- «Часть операций работает бесплатно, без ключа» — у media-gen, но это архитектурный вопрос самого CLI `velsvisual`, не текстовая правка SKILL.md.

## Открытый вопрос

Неизвестно, является ли выбор именно VelsVisual (а не одной из альтернатив) случайным или осмысленным (личное знакомство с автором, доверие, специфическая причина) — это меняет вес сравнения и известно только владельцу библиотеки.

## Решение

Открытый вопрос — принимает владелец библиотеки, не Skill System и не Исследователь.
