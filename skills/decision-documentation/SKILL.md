# Decision Documentation

## Principle

Решение без записанной причины бесполезно при следующей проверке: через три месяца никто не вспомнит, почему было принято именно так. Значимое решение — не разовая задача — документируется как решение, а не как факт: что решается, почему именно так, что было отклонено и почему, откуда пришла информация.

## Implementation (в этом проекте — Foundation)

Формат уже есть в `DECISIONS.md` (см. Foundation): статус (`Proposal` → `Discussion` → `Locked`, либо `Отклонено`), что решается, обоснование, отклонённые альтернативы, источник. Переход в `Locked` — только по явному подтверждающему слову владельца («принимаем», «фиксируем», «зафиксируй», «LOCKED»), никогда не выводится из тона реплики.

**Важно про радиус поражения**: если решение меняет саму методологию работы агента (а не разовую задачу для одной сессии) — переход в `Locked` заблокирован до независимой проверки отдельным, изолированным ходом рассуждений. Не переводи такое решение в `Locked` в том же ответе, где оно предложено — оставляй `Proposal`.

## Когда применять

- Решение переживёт текущий диалог или затронет файлы устава (`HOME.md`, `SOUL.md`, `ROUTING.md`, `DECISIONS.md` — формат).
- Владелец прямо спрашивает «что мы решили по X».
- Перед новым предложением — проверить, не `Locked` ли это уже и не отклонялось ли раньше с обоснованием.

## Когда НЕ применять

Рядовые задачи, не прошедшие входной фильтр по значимости — записи не создают, сверяться с файлом не обязаны (правило самого `DECISIONS.md`). Не документируй то, что не переживёт сессию.

## Integration-происхождение

Материализация карточки Integration «ADR discipline» (`research/AI-Engineering/03-full-report.md` §1) — рыночная ADR-дисциплина (Context+Decision+Consequences) подтвердила уже существующий у Foundation формат как несущий, не декоративный. Что взято из рынка: сама *ценность* явного обоснования+альтернатив как формата, не подлежащего пропуску. Что не взято: поле «Последствия» отдельно от «Обоснования» — предложено как Proposal в `Foundation/04_REPOSITORY/DECISIONS.md` (2026-08-11), не Locked, не встроено в этот Skill до отдельного решения владельца.
