# youtube-analysis
## Воспроизводимая процедура: исчерпать доступные способы до сообщения об ограничении

Критерий вызова: пользователь прислал ссылку на YouTube-видео.

Логика — не «не умею смотреть», а «исчерпай доступные способы, потом говори
об ограничении»:

1. **Субтитры.** `yt-dlp --write-subs --write-auto-subs --sub-langs "ru,en"
   --skip-download`. Если есть — скачать. Авто-субтитры в формате VTT
   дублируют строки построчно (rolling captions) — обязательно
   дедуплицировать в чистый транскрипт перед чтением, иначе файл в разы
   длиннее реального текста и тратит контекст впустую.
2. **Транскрипция.** Если субтитров нет — предложить/выполнить транскрипцию
   аудио (Whisper или аналог, если доступен в среде).
3. **Кадры.** Если 1 и 2 недоступны — использовать доступные
   кадры/видеофайл для анализа визуальной части (например, через
   `claude-in-chrome` skill — открыть видео и снять кадр в нужный момент).
4. Только после исчерпания 1–3 — сообщать об ограничении. Не раньше.

**Метаданные** (title, channel, description, duration) — через
`yt-dlp --dump-json`, писать результат в файл через Python с явным
`encoding="utf-8"`, не читать напрямую из stdout терминала — кириллица
ломается через кодировку bash/PowerShell при прямом выводе.

**После завершения анализа** — автоматически переходить к Opportunity
Discovery (`skills/opportunity-discovery.md`), не останавливаться на
пересказе содержания видео как финальном ответе.
